INSTALL

Two steps to the street.

This page puts the OpenABL bootloader on the handheld over USB, which only needs doing once. Then BananaLinux Flasher writes the microSD card. Android stays where it is.

Retroid Pocket Classic only (Snapdragon G1 Gen 2, SM4450). The page checks the device and refuses anything else. A bootloader for the wrong chipset is the one way to brick a handheld. Use it at your own risk.

1a · Bootloader file

Download abl_signed-SM4450.elf from the OpenABL v1.2 release, then pick it here. The page checks its sha256 before it will flash it.

OpenABL v1.2 by the OpenHandheldCollective, unmodified, GPL-3.0-or-later: licence and source.

1b · Connect the handheld

  1. Power the handheld off.
  2. Hold Volume Down and press Power: it opens fastboot.
  3. Plug it into this computer with a USB-C data cable, then press Connect and pick it.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer (Firefox and Safari don't have WebUSB).

A stock handheld then restarts once into fastbootd (its own bootloader can't flash): press the button that appears, wait for the fastbootd screen, and press Connect again.

The handheld doesn't show up

Windows: install the Google USB driver, replug, try again.

Linux: let your user open fastboot devices, then replug:

echo 'SUBSYSTEM=="usb", ENV{ID_USB_INTERFACES}=="*:ff4203:*", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/51-fastboot.rules
sudo udevadm control --reload-rules

Close anything else using it: a running fastboot or adb server holds the device (adb kill-server).

1c · Flash OpenABL

Writes OpenABL to both bootloader slots (abl_a, abl_b) and restarts the handheld. Don't unplug it until this says done.

2 · Write the card

BananaLinux Flasher downloads the newest Banana Pocket release, checks it and writes it to the microSD. Pick Retroid Pocket Classic, pick the card, press Download & Flash. Everything on the card is erased.

⬇ BananaLinux Flasher

Windows .exe and Linux AppImage. On macOS, use the flasher from source or balenaEtcher with banana-retroid-pocket-classic.img.gz from the latest release.

3 · First boot

  1. Put the card in the handheld. Hold Volume Down and press Power for the OpenABL menu.
  2. Set Boot mode → Linux and Boot source → Auto, then Start. OpenABL remembers these, so after this an ordinary power-on boots Banana Pocket.
  3. The first boot takes a few seconds longer while it makes the games partition. The first-time setup opens next.

Getting Android back: set Boot mode → Android in the same menu. More detail, and what to do when something goes wrong, is in the install guide.
